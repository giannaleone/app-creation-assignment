## App Description
Room Makeover Planner is a Streamlit app that helps users plan and organize a room redesign from start to finish. Users will choose a room type and decor style, set a budget, and build a shopping list of furniture and decor items with prices. The app will track total spending against the budget, display a color palette for the room, and show how far along the makeover is as items are purchased or set up. A Supabase database is planned for saving plans and items in a later assignment.

## Intended Users
This app is intended for college students, renters, and first-time homeowners who want to redecorate on a budget but feel overwhelmed by the process. It is also useful for anyone who wants one place to keep track of their ideas, costs, and progress.

## Planned Features
- Room and style selector (room type, decor style, room size)
- Budget tracker showing total spent, money remaining, and an over-budget warning
- Shopping list with item name, price, store, category, and priority
- Color palette picker that displays chosen colors with hex codes
- Progress tracker with checkboxes for purchased or installed items
- Downloadable summary of the finished plan
